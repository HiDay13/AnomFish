# AnomFish
AnomFish · Атлас рыб

## Страницы для поисковиков

Основной адрес: https://hiday13.github.io/AnomFish/

- `fish/*.html` — 137 самостоятельных страниц без зависимости от JavaScript.
- `sitemap.xml` — главная и все страницы улова.
- `scripts/build-seo.mjs` — пересборка страниц после обновления `data.json`: `node scripts/build-seo.mjs`. Формулы редкости общие с приложением (`core.mjs`).
- Ссылки на все страницы есть на главной; в открытой карточке есть ссылка «Отдельная страница».

### robots.txt на GitHub Pages

Файл должен открываться по адресу https://hiday13.github.io/robots.txt. В папке `/AnomFish/` он не управляет обходом. Здесь сохранён готовый шаблон для корневого сайта `HiDay13.github.io`; его настройки этой правкой не менялись. Отсутствие robots.txt само по себе не запрещает индексацию.

Карту https://hiday13.github.io/AnomFish/sitemap.xml можно отправить в Google Search Console и Яндекс Вебмастер после подтверждения сайта. Индексация зависит от поисковой системы и не гарантируется самим добавлением карты.
